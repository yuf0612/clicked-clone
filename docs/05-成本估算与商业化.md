## 三、商业化设计（对标 Clicked）

### 定价方案（工程内已配置）
| 方案 | 建议价格 | 定位 |
|------|---------|------|
| 周订阅 | ¥12/周 | 短期尝鲜 |
| 月订阅 | ¥48/月 | 主力 |
| 年订阅 | ¥198/年（约 ¥16.5/月） | 最划算，主推 |
| 终身买断 | 可选 | 一次性 |

### 免费 vs Pro 权益切分
| 功能 | 免费用户 | Pro 用户 |
|------|---------|---------|
| 相机 / 定时 / 样片叠加 | ✅ | ✅ |
| 基础滤镜 | 部分 | 全部 55 个 |
| 手动调整 / 美颜 | 部分 | 全部，无限次 |
| AI 风格 | 3 次/天 | 30 次/月（或无限） |
| 移除物体 | ❌ | ✅ |
| 高清无水印导出 | ❌ | ✅ |

### 收入模型测算（示意）
假设：月活 5,000，付费转化率 3%（150 人），其中 60% 选年付、40% 选月付：
- 年付：90 人 × ¥198 = ¥17,820（摊到当月约 ¥1,485）
- 月付：60 人 × ¥48 = ¥2,880
- **月流水约 ¥4,365**，需覆盖 AI 成本 + 苹果抽成（15-30%）

> 注：苹果对小开发者年收入 < $100 万抽成 15%，否则 30%。

## 四、成本优化建议

1. **AI 调用放服务端 + 缓存**：相同图片/风格结果缓存，减少重复调用。
2. **额度控制**：免费用户每日 3 次（工程已实现），防止薅羊毛。
3. **分级模型**：简单风格走当前 OpenCV 后端（零成本），复杂效果才升级付费模型。
4. **零成本起步验证市场**：当前后端纯开源算法、无需付费 Key，可零成本验证用户是否买账，再决定是否升级深度学习模型。
