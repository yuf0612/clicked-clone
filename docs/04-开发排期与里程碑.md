# 04 · 开发排期与里程碑

## 前提说明

本工程已完成 **v1.0 约 60% 的编码工作**（完整 UI + 核心拍摄/编辑逻辑）。下表分两种视角：
- **如果你用这个工程**：只需做"接入 + 上线"部分，约 2-5 周。
- **如果从零开发**：完整周期约 10-14 周。

排期以"1 名熟练 iOS 工程师"为基准。

---

## 关键路径与风险

| 风险点 | 影响 | 应对 |
|--------|------|------|
| 苹果审核被拒 | 上架延期 | 提前准备隐私政策、避免敏感权限滥用 |
| AI 服务不稳定/太贵 | AI 功能体验差 | 多服务商备选、设置额度上限 |
| 人脸对齐精度不够 | 自动快门不好用 | 换 FaceUnity 等专业 SDK |
| 没有 Mac | 无法开发 | 租云 Mac 或找人合作 |
