# 03 · UI 设计与交互说明

## 1. 设计语言

| 维度 | 定义 |
|------|------|
| 整体风格 | 年轻、潮流、轻质感，对标 Clicked 的"网红审美" |
| 主色 | 粉→紫渐变（#FA5C8D → #8C59F2），用于品牌按钮、会员卡 |
| 相机/编辑器底色 | 深灰黑（#121214），让照片成为视觉焦点 |
| 强调色 | 黄色（快门选中、滤镜选中、提示标签）；绿色（对齐成功） |
| 字体 | 系统字体（SF Pro / 苹方），标题加粗 |
| 圆角 | 卡片 16px，按钮胶囊形（30px），头像圆形 |
| 图标 | SF Symbols 系统图标 |

设计意图：**界面尽量克制，把注意力留给照片本身**；相机与编辑页用深色，引导页与付费页用亮色渐变制造情绪反差。

## 2. 页面结构与导航

```
App 启动
  │
  ├─ 未看过引导 → OnboardingView（3 页滑动引导）
  │                  └─ 点"开始使用" → 主界面
  │
  └─ 看过引导 → 主界面（TabView，4 个 Tab）
                   ├─ Tab 0：CameraView（拍照，默认页）
                   │     └─ 拍完 → CapturePreviewView（重拍/使用）
                   │           └─ "使用照片" → 跳 Tab 1
                   ├─ Tab 1：EditorView（编辑）
                   │     └─ 点 AI → 未订阅时弹 SubscriptionView
                   ├─ Tab 2：PhotoLibraryView（相册）
                   │     └─ 点照片 → PhotoDetailView（重编辑/导出/删除）
                   └─ Tab 3：ProfileView（我的）
                         └─ 点 Pro 卡 → SubscriptionView
```

## 3. 各页面设计说明

### 3.1 新手引导（OnboardingView）
- 全屏粉紫渐变背景，3 页滑动
- 每页：大图标 + 标题 + 一句话说明
- 三页主题：①照着样片拍 ②拍照时有指导 ③一键变精致
- 底部：页面指示点 + "开始使用 / 跳过引导"主按钮 + "下一步"

### 3.2 相机页（CameraView）—— 核心页
- **顶部**：关闭(X) + 定时(timer，带秒数角标) + 连拍(带张数角标) + 样片叠加(透明度菜单)
- **中部**：相机实时预览铺满；有样片时半透明叠加（透明度可调）
- **PicScan 提示气泡**：画面上部，列出 AI 建议（走近点/转向光/向左微调），可刷新
- **Smart Guide 指示**：画面中央绿色进度环 + "对齐面部"提示
- **倒计时**：全屏半透明遮罩 + 大号数字
- **底部**：
  - 功能标签行：样片跟拍 / 场景指导 / 自动快门（点亮状态）
  - 主控件行：左=样片(相册) 中=快门(渐变圆) 右=翻转摄像头
  - 开关行：智能自动拍摄 Toggle + 分析场景按钮
- **拍完**：全屏确认页，底部"重拍"+"使用照片"

### 3.3 编辑页（EditorView）
- **顶部**：返回 + "编辑"标题 + 复制/粘贴/重置图标
- **中部**：图片预览（长按看原图，顶部有提示标签）
- **工具区**：4 个标签（滤镜/调整/美颜/AI）
  - 滤镜：分类横滑 + 55 个滤镜色块横滑（选中黄框）+ 强度滑块
  - 调整：5 个参数滑块（亮度/对比度/饱和度/曝光/色温）
  - 美颜：磨皮/亮眼/光泽 3 个滑块
  - AI：风格标签横滑 + 剩余额度 + 移除物体入口
- **底部**："保存照片"渐变主按钮

### 3.4 相册页（PhotoLibraryView）
- 三列网格展示作品，点开看大图
- 详情页底部：重新编辑 / 导出 / 删除

### 3.5 个人中心（ProfileView）
- 头像 + 会员标识
- Pro 升级卡（未订阅时）
- 设置列表：深色模式开关、恢复购买、（订阅后）当前方案

### 3.6 订阅页（SubscriptionView）
- 顶部皇冠 + 标题 + 副标题
- 权益列表（5 项，带图标）
- 方案卡片（周/月/年，年卡标注"最划算"并高亮）
- 底部：7 天免费试用主按钮 + 恢复购买 + 自动续费说明小字

## 4. 关键交互细节

| 交互 | 行为 |
|------|------|
| 长按编辑页图片 | 临时显示原图，松手回到效果 |
| 滤镜重复点选 | 再次点同一滤镜 = 取消该滤镜 |
| 自动快门对齐 | 分数 > 0.85 自动拍，2 秒冷却防连拍 |
| 定时器 | 倒计时期间禁止再次触发快门 |
| AI 额度耗尽 | 弹订阅页，不阻断其他功能 |
| 权限被拒 | 弹窗说明去系统设置开启 |
