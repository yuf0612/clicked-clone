# 02 · 技术架构设计

## 1. 技术栈总览

| 层次 | 技术 | 说明 |
|------|------|------|
| UI 框架 | SwiftUI（iOS 17+） | 声明式界面，代码量少 |
| 架构模式 | MVVM | View / ViewModel / Model 分离 |
| 相机 | AVFoundation | AVCaptureSession + AVCapturePhotoOutput |
| 人脸检测 | Vision 框架 | VNDetectFaceRectanglesRequest（系统自带，免费） |
| 图像处理 | Core Image | CIFilter 滤镜链，KVC 写法 |
| 相册 | PhotosUI + Photos | PhotosPicker 选样片，PHPhotoLibrary 保存 |
| 订阅 | StoreKit 2 | Product / Transaction 现代 API |
| 响应式 | Combine | 参数变化自动触发预览重绘 |
| 工程生成 | XcodeGen | project.yml 一键生成 .xcodeproj |

## 2. 分层架构图

```
┌─────────────────────────────────────────────┐
│                  View 层                      │
│  CameraView / EditorView / OnboardingView /   │
│  PhotoLibraryView / ProfileView /             │
│  SubscriptionView / ContentView               │
│  职责：展示 UI、接收用户操作                    │
└───────────────┬─────────────────────────────┘
                │ @EnvironmentObject / @StateObject
┌───────────────▼─────────────────────────────┐
│               ViewModel 层                    │
│  CameraViewModel / EditorViewModel /          │
│  AppState / SubscriptionManager               │
│  职责：界面状态、业务逻辑、数据流转             │
└───────────────┬─────────────────────────────┘
                │ 直接调用
┌───────────────▼─────────────────────────────┐
│               Service 层                      │
│  CameraService │ ImageProcessor │             │
│  FaceDetectionService │ AIService │            │
│  PhotoLibraryService │ PresetData             │
│  职责：封装系统能力、可替换的第三方接入点        │
└───────────────┬─────────────────────────────┘
                │
┌───────────────▼─────────────────────────────┐
│            Model 层 + 系统框架                 │
│  FilterPreset / Adjustments / EditSession /   │
│  SavedPhoto │ AVFoundation │ CoreImage │ Vision│
└─────────────────────────────────────────────┘
```

**设计原则**：
- View 只负责展示，不写业务逻辑
- Service 层可替换：AIService 内部走 `APIClient`（生产级网络层）调用 Python 后端真实算法，网络不可用时自动降级到本地 Core Image / 几何算法，上层无感知
- 全局状态（AppState / SubscriptionManager）用 `@EnvironmentObject` 注入，避免层层传参
- 相机帧回调在后台队列，所有 `@Published` 状态写回统一收拢到主线程，避免 SwiftUI 并发警告

## 3. 关键数据流

### 3.1 拍照 → 编辑 的数据流
```
用户点快门
  → CameraService.capturePhoto()
  → AVCapturePhotoCaptureDelegate 回传 UIImage
  → CameraViewModel.capturedImage
  → 用户点"使用照片"
  → AppState.imageToEdit = image（触发 imageToEditToken 更新）
  → EditorView 监听 token → EditorViewModel.loadImage()
  → EditSession 建立
```

### 3.2 编辑参数 → 预览重绘（响应式核心）
```
用户拖滑块
  → ViewModel.updateAdjustment(\.brightness, value)
  → 修改 EditSession 副本 → 重新赋值给 @Published session
  → Combine $session 发布变化
  → receive(on: 后台队列) → ImageProcessor.process(session) 生成新图
  → receive(on: 主线程) → @Published previewImage 更新
  → SwiftUI 自动刷新图片预览
```
> 关键点：图像处理放在后台队列，避免阻塞主线程导致界面卡顿。

### 3.3 样片叠加
```
用户点"样片"按钮 → PhotosPicker 系统相册
  → loadTransferable(Data) → UIImage
  → CameraViewModel.setOverlay()
  → CameraView 在相机预览层之上叠加半透明 Image
  → opacity 由滑块控制
```

## 4. 模块职责说明

| 文件 | 核心职责 | 关键技术点 |
|------|---------|-----------|
| CameraService | 相机权限、会话、拍照、切换摄像头 | AVCaptureSession 在后台线程 startRunning |
| CameraViewModel | 倒计时、连拍、自动快门、样片状态 | Timer + 防重复触发标志位 |
| ImageProcessor | 滤镜/调整/美颜/导出 | CIFilter KVC + 键存在性校验，避免崩溃 |
| FaceDetectionService | 人脸框检测、对齐打分 | Vision VNFaceObservation，居中度+大小评分 |
| APIClient | 生产级网络层 | URLSession async/await + 超时/重试/缓存 + 错误处理 |
| AIService | AI 编排 + 额度管理 | 网络调用真实后端，失败自动本地降级；UserDefaults 额度计数 |
| PhotoLibraryService | App 沙盒存储 + 系统相册 | JSON 元数据 + 沙盒图片 + PHPhotoLibrary |
| EditorViewModel | 编辑会话状态、复制粘贴编辑 | Combine 响应式重绘管线 |
| SubscriptionManager | StoreKit 2 购买/恢复/权益校验 | @MainActor + Transaction.updates 监听 |

## 5. 性能与稳定性设计

1. **图像处理后台化**：滤镜链计算在 `DispatchQueue.global(userInitiated)` 执行，主线程只更新结果。
2. **KVC 键校验**：给 CIFilter 设值前用 `inputKeys` 过滤，避免 `NSUnknownKeyException` 崩溃。
3. **避免强制解包**：AI 风格映射用可选绑定；`preset(named:)` 有兜底。
4. **相机生命周期**：onAppear 启动 session，onDisappear 停止，省电且避免占用冲突。
5. **自动快门防抖**：触发后 2 秒内不再重复触发。

## 6. 扩展性设计（从哪里升级能力）

当前 AI 三大能力已走真实后端算法（见 `server/app.py`），以下表格说明未来想进一步升级时改哪里：

| 要升级的能力 | 当前实现 | 升级位置与方法 |
|------------|---------|--------------|
| AI 风格 | 后端 OpenCV 处理链 | 改 `server/app.py` 的 `apply_style()`，换深度学习模型，App 端无需改 |
| 移除物体 | 后端 OpenCV Telea inpaint | 改 `server/app.py` 的 `remove_object()`，接更强 inpainting 模型 |
| 场景分析 | 后端 Haar 检测 + 构图分析 | 改 `server/app.py` 的 `analyze_scene()`，接多模态模型（保持 JSON 结构）|
| 精准姿态对齐 | Vision 人脸关键点 | 改 `FaceDetectionService.alignmentScore`，接 FaceUnity / ARKit |
| 高级滤镜（LUT） | CIFilter 预设 | 改 `ImageProcessor.applyPreset`，用 CIFilter 加载 .cube LUT |

详见 `docs/06-第三方SDK接入指南.md`。
