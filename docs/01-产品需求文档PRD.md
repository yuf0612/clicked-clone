# 01 · 产品需求文档（PRD）

**产品名**：ClickedClone（可替换为正式品牌名）
**定位**：面向不会拍照的普通人的"手把手 AI 摄影助手"——照着样片拍、拍时有指导、拍完一键美化。
**对标产品**：Clicked: Camera Editor（App Store 上线 7 个月，20 万+ 创作者，评分 4.0）
**目标平台**：iOS 17+，仅 iPhone
**版本**：v1.0 完全体工程（功能真实可用）

---

## 1. 产品背景与核心洞察

大部分人拍照的痛点不是"设备不够好"，而是：
- 不会摆姿势、不会找角度
- 不知道光线怎么用
- 不会修图，滤镜调半天还是不好看

Clicked 的聪明之处在于：**它不只做后期修图，而是把"引导拍摄"做成了核心**——让不会拍照的人也能"照抄"一张好看的照片。本产品复刻这一思路。

## 4. 核心用户故事

**故事 1（样片跟拍）**
> 作为不会拍照的小美，我看到一张喜欢的照片，希望把它变成相机里的引导，照着摆姿势就能拍出相似的构图。
> 验收：选图后半透明叠加正确显示；透明度可调；前后摄像头都能用；移除样片后恢复正常相机。

**故事 2（自动快门）**
> 作为一个人自拍的用户，我架好手机退后，希望在站好位置、脸对齐后手机自动拍，不用跑回去按快门。
> 验收：开启后实时显示对齐分数；分数 > 0.85 自动拍照；有防重复触发机制。

**故事 3（一键出片）**
> 作为不会修图的用户，我希望能一键套用潮流滤镜和自然美颜，还能微调强度。
> 验收：55 个滤镜可切换；强度滑块实时生效；美颜保留真实质感；长按对比原图。

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 滤镜预览实时（<100ms），导出高清图不卡顿 |
| 隐私 | 照片默认只存本地；AI 功能明确告知会上传；隐私政策可查 |
| 可用性 | 相机权限被拒时给出明确引导 |
| 兼容 | iOS 17+，iPhone 全系，仅竖屏 |
| 商业化 | 免费用户每天 3 次 AI；Pro 解锁全部功能 |

---

## 6. 版本路线图（建议）

- **v1.0（当前工程，完全体）**：核心拍摄引导 + 完整编辑 + 真实 AI 三大能力（后端算法 + 本地降级）+ 完整 UI + 订阅框架
- **v1.1**：升级到深度学习级风格迁移（接付费模型，见 docs/06）
- **v1.2**：接入 FaceUnity 等商业 SDK 做精准身体姿态对齐
- **v2.0**：批量出片、云同步、社区样片库

---

## 7. 明确不做（v1.0）

- 不做安卓版（先专注 iOS）
- 不做视频编辑（Clicked 有，但先聚焦照片）
- 不做社区/账号体系（先用本地存储）
- 不内置样片库（用户从自己相册选）
